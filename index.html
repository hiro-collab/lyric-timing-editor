Editor Help

Load a local audio file and a UTF-8 lyric text file, then use the current and next phrase controls while playing the song.

Before publishing, distributing, uploading, or committing files that include lyric text, confirm the lyric rights and the destination terms.

Audio stays in the browser session. The project stores only the file name and optional duration metadata.

Autosave drafts are stored in this browser's IndexedDB and may include lyric text.
