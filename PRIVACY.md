# Privacy Notes

Lyric Timing Editor runs in the browser as a static local-file editor.

- The app does not upload audio, lyrics, Project JSON, exports, or notes.
- The app does not include analytics or tracking.
- Audio files are used through local browser object URLs for playback and metadata only.
- Project JSON, lyric-included exports, WebVTT, LRC, pasted source text, and IndexedDB autosave drafts may contain lyric text.
- Autosave data is stored only in this browser's IndexedDB. Use the in-app Clear Draft action to delete the local autosave draft.

Future features that contact external services, including Songle/TextAlive lookup or hosted storage, require a separate privacy review before release.
